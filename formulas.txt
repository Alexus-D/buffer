omega_m_complex = omega_m - j * alpha
omega_c_complex = omega_c - j * beta

Gamma = sqrt(kappa * gamma)

omega_+ = 1/2 * (omega_c_complex + omega_m_complex + sqrt((omega_c_complex - omega_m_complex)^2 + 4 * (J - j * Gamma)^2))
omega_- = 1/2 * (omega_c_complex + omega_m_complex - sqrt((omega_c_complex - omega_m_complex)^2 + 4 * (J - j * Gamma)^2))

================================================================================
РАЗЛОЖЕНИЕ НА ДЕЙСТВИТЕЛЬНЫЕ И МНИМЫЕ ЧАСТИ
================================================================================

Обозначения:
  Delta_omega = omega_c - omega_m  (расстройка частот)
  Delta_gamma = beta - alpha       (разность затуханий)
  
  A = (Delta_omega)^2 - (Delta_gamma)^2 + 4*J^2 - 4*Gamma^2
  B = 2*Delta_omega*Delta_gamma - 8*J*Gamma
  
  R = sqrt(sqrt(A^2 + B^2))  (модуль квадратного корня)
  phi = 1/2 * atan2(B, A)    (половина фазы)

Тогда:
  sqrt((omega_c_complex - omega_m_complex)^2 + 4*(J - j*Gamma)^2) = R*exp(j*phi)
                                                                    = R*cos(phi) + j*R*sin(phi)

Итоговые формулы для собственных частот:

omega_+ = Re(omega_+) + j*Im(omega_+)

  Re(omega_+) = 1/2 * (omega_c + omega_m + R*cos(phi))
  
  Im(omega_+) = 1/2 * (-(alpha + beta) + R*sin(phi))


omega_- = Re(omega_-) + j*Im(omega_-)

  Re(omega_-) = 1/2 * (omega_c + omega_m - R*cos(phi))
  
  Im(omega_-) = 1/2 * (-(alpha + beta) - R*sin(phi))

где:
  R = sqrt(sqrt(A^2 + B^2))
  phi = 1/2 * atan2(B, A)
  A = (omega_c - omega_m)^2 - (beta - alpha)^2 + 4*J^2 - 4*Gamma^2
  B = 2*(omega_c - omega_m)*(beta - alpha) - 8*J*Gamma

================================================================================
ШИРИНЫ ПИКОВ S-ПАРАМЕТРОВ: ВЫВОД
================================================================================

ФОРМУЛА ДЛЯ S-ПАРАМЕТРА:
-----------------------

Для связанной системы резонатор-магнон S-параметр имеет вид:

S21(ω) = S_plato + κ / (i*Δω_c - (κ+β) - g²/(i*Δω_m - (γ+α)))

где:
  Δω_c = ω - ω_c  (расстройка от резонатора)
  Δω_m = ω - ω_m  (расстройка от магнона)
  g = J - i*Γ     (комплексная связь)

УПРОЩЕНИЕ ДЛЯ ОДНОГО ПИКА:
-------------------------

Вблизи собственной частоты ω₀ = ω_r + i*ω_i система ведет себя как 
лоренцевский резонатор:

|S21(ω)|² ≈ A / ((ω - ω_r)² + ω_i²)

где:
  ω_r = Re(ω₀) — центральная частота пика
  ω_i = Im(ω₀) — полуширина затухания (обычно ω_i < 0)

УСЛОВИЕ ПОЛУВЫСОТЫ:
------------------

Пик достигает половины максимума, когда знаменатель удваивается:

(ω - ω_r)² + ω_i² = 2*ω_i²

(ω - ω_r)² = ω_i²

ω - ω_r = ±|ω_i|

Следовательно, ПОЛНАЯ ширина на полувысоте (FWHM):

FWHM = 2*|ω_i| = 2*|Im(ω₀)| = -2*Im(ω₀)

(минус потому что Im(ω₀) < 0 для затухающего резонанса)

ПРИМЕНЕНИЕ К НАШИМ МОДАМ:
------------------------

width_+ = -2 * Im(omega_+) 
        = -2 * [1/2 * (-(alpha + beta) + R*sin(phi))]
        = (alpha + beta) - R*sin(phi)

width_- = -2 * Im(omega_-) 
        = -2 * [1/2 * (-(alpha + beta) - R*sin(phi))]
        = (alpha + beta) + R*sin(phi)

Где:
  width_+ — полная ширина на полувысоте для моды omega_+
  width_- — полная ширина на полувысоте для моды omega_-
  
ФИЗИЧЕСКИЙ СМЫСЛ:
----------------
  - Ширина пика определяется скоростью затухания энергии в системе
  - Базовая ширина (alpha + beta) — сумма затуханий резонатора и магнона
  - Поправка R*sin(phi) — перераспределение затуханий из-за связи
  - При сильной связи одна мода "отбирает" затухание у другой:
    * Узкая мода (меньше width) — более долгоживущая
    * Широкая мода (больше width) — быстрее затухает
